# VANKO VPN — website

Полностью готовый статический сайт для GitHub Pages.

## Структура
- `index.html` — главная
- `documentation.html` — документация
- `rules.html` — правила
- `terms.html` — соглашение
- `privacy.html` — конфиденциальность
- `refund.html` — возврат
- `style.css` — стили
- `logo.png` — основной логотип VANKO VPN
- `favicon.png` — favicon
- `files/` — материалы документации

В документации оставлены только:
- Быстрый старт
- Подключение на устройствах
- FAQ

Для GitHub Pages загружай содержимое архива в корень репозитория.
