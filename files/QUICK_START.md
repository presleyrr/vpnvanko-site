# VANKO VPN — Быстрый старт

1. Откройте Telegram-бота: https://t.me/vpnvankobot
2. Выберите сервер.
3. Выберите своё устройство.
4. Получите конфигурацию после подключения серверной части.
5. Установите совместимый VPN-клиент.
6. Импортируйте конфигурацию.
7. Включите VPN и проверьте соединение.

Важно: этот файл является инструкцией. Рабочую конфигурацию должен выдавать ваш реальный VPN-сервер.
