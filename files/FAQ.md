# Частые вопросы

### Где получить данные для подключения?
Открой @vpnvankobot и выбери «⚡ Подключиться». Бот проведёт тебя по настройке.

### Какие серверы доступны?
В интерфейсе VANKO VPN доступны локации NL, DE, FI и US.

### На каких устройствах работает VANKO VPN?
Поддерживаются iPhone/iPad, Android, Windows и macOS — при наличии совместимого VPN-клиента.

### Почему моя конфигурация не работает?
Проверь срок действия подписки, сервер, интернет-соединение и настройки клиента. При необходимости запроси актуальную конфигурацию в боте.

### Можно ли отправлять свой приватный ключ другим?
Нет. Приватный ключ — секретная часть конфигурации. Не публикуй его в чатах, GitHub или на сайте.

### Где получить помощь?
Используй раздел «❓ Помощь» в @vpnvankobot.
